Settings and recovery

Unchanged saves are skipped and brightness applies immediately. Other changes restart the frame. Wi-Fi changes try the new connection for three minutes and restore the previous settings if it fails. Keep this page’s address or reconnect to the setup network if needed.

Changing tenant or app IDs requires Microsoft sign-in again. Reset sign-in to use another account; frame settings are kept.
