Daddy Status web flasher

Release __TAG__ for a classic ESP32 with 4 MB flash. Connect the board over USB and use a Chromium browser such as Chrome or Edge; Web Serial is not available in Firefox or Safari. Flashing a factory image erases saved settings and Microsoft sign-in.

Factory image, no wireless updates

Default configuration: LED data on GPIO 25, no OTA endpoint. Later updates require the USB cable again.

Frame image with signed wireless updates

Picture-frame wiring: LED data on GPIO 13, 10 second presence polling. Enables the OTA upload page with signature verification and boot rollback. The device will only accept future images signed with this project's release key, such as the ota-frame app image from each GitHub release.

The encrypted storage profile is not offered here on purpose: its first boot permanently programs security eFuses and must follow the provisioning guide. After flashing, configure Wi-Fi and the Microsoft app registration through the device's own web page as described in the README. Checksums and the release public key are on the release page.
